TASK: TODAY I HAVE LEARNED THE SQL SUB LANGUAGES IN THAT ONE OF THE COMMANDS IS TCL - TRANSACTION CONTROL LANGUAGE

IT IS MAINLY FOCUS ON THE TRANSACTIONS IN A TABLE

THERE ARE THREE TYPES
1, COMMIT TRANSACTION
2, ROLLBACK TRANSACTION
3, SAVE TRANSACTION

1, COMMIT TRANSACTION: THE COMMIT IS USED FOR SAVE CHANGES WHEN WE TRANSACTION IS DONE IN A DATABASE TABLE ONCE A TRANSACTION IS COMMITTED THE CHANGES ARE PERMANENT

SYNTAX:

BEGIN TRANSACTION

SQL STATEMENT

COMMIT TRANSACTION

FIRST WE HAVE TO RUN THE BEGIN TRANSACTION AND SQL STATEMENT AND THEN IT WILL UPDATE IN A TABLE AND IF YOU WANT TO SAVE PERMANENT THEN RUN THE COMMIT TRANSACTION THEN IT WILL BE SAVED PERMANENT

2, ROLLBACK: THE ROLLBACK COMMAND UNDOES ALL CHANGES IN THE CURRENT STATEMENT USEFUL SOMETHING GOES WRONG IMMEDIATELY IT WILL CHANGE THE ORIGINAL STAGE

SYNTAX:

BEGIN STATEMENT
SQL STATEMENT
ROLLBACK

WE HAVE TO RUN THE BEGIN TRANSACTION AND SQL STATEMENT AND THEN IT WILL RUN IF ANY OCCURS IT WILL ROLLBACK AND IT WILL COME TO ORIGINAL STATEMENT

3, SAVE TRANSACTION: WHEN WE ARE WRITING THE TWO TRANSACTIONS WHEN WE HAVE ANY ERROR THEN WE CAN SEPARATE A TRANSACTION BY USING THE SAVE TRANSACTION

SYNTAX:

BEGIN TRANSACTION

SQL STATEMENT

SAVE TRANSACTION (SAVE POINT NAME)

SQL STATEMENT

ROLLBACK (SAVE POINT  NAME)
