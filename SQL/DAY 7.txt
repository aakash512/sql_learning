VIEW: THE  VIEW IS STORED THE SQL TATEMENT LIKE COMPLEX STATEMENT STORED THE QUERY IN THE A VIEW 

SYNTAX: (CREATE VIEW VM_TABLE_NAME
        AS 
        SQL STATEMENT)

ALTER VIEW: IN SQL SERVER VIEW CAN BE UPDATE WITH THE ALTER VIEW STATEMENT 

SYNTAX: (CREATE OR ALTER VIEW VM_TABLE_NAME
         AS
         SQL STATEMENT)

THERE ARE THREE TYPES:
1)SIMPLE VIEW
2)COMPLEX VIEW
3)INDEXS VIEW
S
SIMPLE VIEW: THE SIMPLE VIEW CONTAIN THE A  SINGLE BASE TABLE 

COMPLEX VIEW: THE COMPLEX VIEW CONTAIN THE A DATA FROM MULTIPLE BASE TABLES OR CONTAINS AGGREGATE FUNCTIONS,GROUPING,DISTINCT VALIES

INDEXS VIEW: A STANDARD SQL SERVER VIEW THAT HAS BEEN PHYSICALL SAVED TO DISK
